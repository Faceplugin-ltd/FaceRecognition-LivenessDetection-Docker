# Runtime libraries

Download the **FaceRecognition_FullSDK_Linux** Drive folder into `cpu/`:

https://drive.google.com/drive/folders/1Lzz3eb_JMDZ0xyGtnGzxsUmMbgaYzin6

Expected files (CPU):

- `libFaceRecognitionSDK.so`
- `libfar-eng.so`, `libfar-sec.so`, `libonnxruntime.so.1`, `far.fpk`
- `libfal-eng.so`, `fal.fpk`

Then `./run.sh` or `docker compose up --build`.
